    Project details

    Image processing and machine learning for alphabet recognition.

    01

    Image processing and OCR

    Built a Python workflow to load images, prepare them with OpenCV tools, and extract text using pytesseract.

    02

    Alphabet classification

    Adapted the MNIST classification approach to recognize alphabet characters from images and iterated on the model to improve test accuracy.

    03

    Model experiments

    Compared logistic regression with neural network models, using scikit-learn and Keras to classify letters in images.
